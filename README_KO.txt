[핵심 변경]
GENERATE로 만든 패턴은 PLAY를 누르면 32 STEP(2마디)이 끝난 즉시 다시 1 STEP으로 돌아가 계속 반복됩니다.
GENERATE 시 PATTERN 모드가 자동 선택되어, 비어 있는 B/C/D 패턴 때문에 긴 무음이 생기지 않습니다.

[SONG 모드]
SONG 모드를 직접 선택한 경우 A B C D 체인을 반복합니다.
단, 노트가 전혀 없는 빈 패턴은 자동으로 건너뛰어 불필요한 무음 구간이 생기지 않습니다.

[재생 중 GENERATE]
곡이 재생 중인 상태에서 GENERATE를 다시 누르면 이전 예약 음을 중단하고 새 패턴의 1 STEP부터 곧바로 재생합니다.
